# 更新日志

本文档记录了项目的所有重大变更。

## [2026-07-01]

### 新增

- 新增「自选股」桌面小组件，支持查看 A 股、ETF、港股和指数行情。
- 支持按名称或代码搜索添加标的，自选列表保存在浏览器本地。
- 支持单列和双列两种行情展示模式，双列模式更适合快速浏览涨跌幅。

### 优化

- 新增暂时关闭和收盘后隐藏开关，行情很差或 A 股休市时可以减少干扰。
- 添加满仓、开关状态等组件内气泡提示，并为关键图标按钮提供 hover 说明。
- 优化搜索候选浮层，避免被小组件容器裁切。
- 自选股组件滚动条跟随当前主题，在包豪斯和麦金塔主题下保持一致视觉。

### 兼容性

- 行情刷新优先使用东方财富数据源，失败时对 A 股、ETF 和港股回退到腾讯行情源。

## [2026-06-29]

### 修复

- 修复链接卡片标签底部对齐问题。链接卡片现在使用占满高度的纵向布局，标签行会稳定停靠在卡片底部区域。
- 新增链接卡片布局回归测试，防止标签行在后续样式调整中重新漂移。

## [2026-06-28]

### 新增

- 新增「麦金塔 1984」复古主题，用黑白像素边框、经典窗口标题栏、内凹按钮和灰阶桌面纹理还原早期 Macintosh System 风格。
- 主题列表新增「麦金塔 1984」选项，可与简约主题、赛博朋克主题、包豪斯经典三原色主题一起切换使用。

### 优化

- 优化麦金塔主题下的桌面侧边导航、主题切换按钮、天气定位控件、空气质量标签、热榜和链接卡片，避免小组件内容错位或被窗口装饰挤压。

### 测试

- 新增麦金塔主题样式回归测试，覆盖主题注册、选择器隔离、卡片标题栏留白和小组件对齐。
